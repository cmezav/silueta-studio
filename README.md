# Silueta Studio

App web local de una sola página. Abre `index.html` directamente en Chrome o Edge; no requiere npm.

Incluye: máscara por canal alfa, suavizado geométrico 0–500, modos Original/Color/Imagen, rueda de color + HEX, transformación del relleno con posición, zoom, ancho, alto y volteo horizontal/vertical, y exportación PNG a resolución original.

La vista previa ahora muestra las etiquetas fuera del área de imagen y respeta la relación de aspecto original de cada imagen.
